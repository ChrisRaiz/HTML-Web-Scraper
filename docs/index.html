HTML Web Scraper

Downloads a static web page with Requests, parses it with Beautiful Soup, and pulls out exactly the pieces you want. This project reads a sample job board and prints every Python job's title, company, location, and apply link.

  • 100job listings parsed
  • 10Python jobs matched
  • 4fields per job

1Overview

HTML Web Scraper is a short, heavily commented Python script that shows the core web scraping workflow for static pages: pages whose content is already in the HTML the server sends back.

It targets Fake Python Jobs, a practice site from Real Python that lists 100 made-up job postings. The script:

  1. Downloads the page with requests.get().
  2. Parses the HTML into a tree with Beautiful Soup.
  3. Finds the results container by its id, then every job card inside it by class.
  4. Filters the cards to jobs whose title mentions Python.
  5. Prints each match's title, company, location, and links.

2Requirements and installation

You need Python 3 and two packages: Requests and Beautiful Soup 4.

  1. Clone the repo and move into it:
    bash
    git clone https://github.com/ChrisRaiz/HTML-Web-Scraper.git
cd HTML-Web-Scraper
  2. Create and activate a virtual environment:
    bash
    python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
  3. Install the dependencies while the environment is active:
    bash
    pip install requests beautifulsoup4

Run deactivate to leave the virtual environment when you're done.

3Usage

Run the script from the project folder:

bash
python3 static_web_scraper.py

Nothing is saved to disk. Everything is printed to the terminal in this order:

OrderWhat's printed
1The raw HTML of the whole page
2The results container, indented with .prettify()
3All 100 job card elements
4The title, company, and location of all 100 jobs
5The title, company, and location of the 10 Python jobs
6Every link in the 10 Python job cards, each prefixed with "Apply Here:"
The first three steps are there to show what each stage of parsing looks like, so the full output runs to about 10,000 lines. Comment out the print calls you don't need, or pipe the output into a file with python3 static_web_scraper.py > output.txt.

4How it works

The script narrows the page down in stages, from the whole document to a single piece of text.

1. Download and parse

requests.get() fetches the page. page.content holds the raw bytes, which Beautiful Soup turns into a tree of elements you can search.

static_web_scraper.py
URL = "https://realpython.github.io/fake-jobs/"
page = requests.get(URL)
soup = BeautifulSoup(page.content, "html.parser")

2. Narrow down to the job cards

Every job sits inside one element with id="ResultsContainer". Searching inside that element, instead of the whole page, avoids matching anything in the header or footer.

static_web_scraper.py
results = soup.find(id="ResultsContainer")
job_elements = results.find_all("div", class_="card-content")

class_ has a trailing underscore because class is a reserved word in Python.

3. Extract text from each card

Inside each card, .find() returns the first matching tag. .text gives its text, and .strip() removes the surrounding whitespace and line breaks.

static_web_scraper.py
for job_element in job_elements:
    title_element = job_element.find("h2", class_="title")
    company_element = job_element.find("h3", class_="company")
    location_element = job_element.find("p", class_="location")
    print(title_element.text.strip())

4. Filter by text, then walk up the tree

Passing a function as string= matches tags by their text. This finds the <h2> headings that mention Python, in any capitalization.

static_web_scraper.py
python_jobs = results.find_all(
    "h2", string=lambda text: "python" in text.lower()
)
python_job_elements = [
    h2_element.parent.parent.parent for h2_element in python_jobs
]

A match is only the heading, but the company, location, and links are elsewhere in the card. Going up three parents (h2 → div.media-content → div.media → div.card-content) returns the whole card.

5. Read link addresses

Tag attributes work like dictionary keys, so link["href"] reads a link's address.

static_web_scraper.py
for link in job_element.find_all("a"):
    print(f"Apply Here: {link['href']}")

5Adapting it to another site

  1. Check that the page is static. Open the page, choose View Page Source, and search for the data you want. If it's in the source, this approach works. If it only appears in the browser's Inspect panel, the page is built with JavaScript (see Troubleshooting).
  2. Find the selectors. Right-click the data and choose Inspect. Note the tag names, classes, and any id on the container around the items.
  3. Update the script. Change URL, the id passed to soup.find(), and the tag and class names in each find() and find_all().
  4. Check the parent depth. If you keep the text filter, count how many levels separate the matched tag from the item container, and change .parent.parent.parent to match.

A few small improvements are worth making for real use:

python
page = requests.get(URL, timeout=10)
page.raise_for_status()                # stop on 404s and server errors

# Keep only the Apply link instead of every link in the card
apply_link = job_element.find("a", string="Apply")["href"]

# Skip headings with no plain text instead of raising an error
string=lambda text: text and "python" in text.lower()

To save results instead of printing them, collect each job in a list of dictionaries and write it out with Python's built-in csv module.

6Troubleshooting and limitations

ProblemCauseFix

ConnectionError or the script hangsNo network connection, or the site is slow to respondCheck your connection and add timeout=10 to requests.get().

Scrape responsibly: Fake Python Jobs is built for practice. Before scraping another site, read its terms of service and robots.txt, and don't send requests faster than a person browsing would.
